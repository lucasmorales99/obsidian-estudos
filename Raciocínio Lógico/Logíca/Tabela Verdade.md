#RacíocioLogico
- Disjunção (V) **ou**
	- A disjunção só é falsa se **todas** as proposições envolvidas forem falsas. Se pelo menos uma for verdadeira, o resultado total é verdadeiro.
- Conjunção (^) **e**
	- A conjunção só é **verdadeira** quando **ambas** as proposições envolvidas (\(p\) e \(q\)) forem verdadeiras. Se pelo menos uma for falsa, o resultado é falso.
- Condicional (->)  **se então...**
	- Apenas falso quando [v, f] 
	- Indica uma dependência lógica entre duas proposições. A primeira parte é a condição (antecedente) e a segunda é a consequência (s_consequente / suceder).
- Bicondicional (<->) **se somente se...**
	- apenas verdadeiro quando [v,v] ou [f,f]
	- A proposição resultante é verdadeira apenas quando as duas proposições simples têm o **mesmo valor lógico** (ambas verdadeiras ou ambas falsas).
- Negação (~) 
	- inverte o valor 


~ simbolo para negação (not)
V simbolo para união (u)
^ simbolo para junção (e)
