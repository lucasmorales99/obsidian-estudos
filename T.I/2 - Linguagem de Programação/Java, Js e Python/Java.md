### 🎓 Aula: Introdução à Linguagem Java

#### 1. O que é o Java?

Imagine que o **Java** é uma **linguagem de programação orientada a objetos**, de **tipagem forte** e de alto nível. Quando dizemos que ela é "orientada a objetos", significa que construímos nossos sistemas pensando em "entidades" ou "módulos" do mundo real (como Objetos e Classes), facilitando a organização, manutenção e reuso do código.

#### 2. O Grande Segredo do Java: "Escreva uma vez, rode em qualquer lugar" (_WORA_)

Antigamente, se você escrevia um código para o Windows, ele não rodava no Linux ou no Mac. O Java resolveu isso com a **JVM (Java Virtual Machine)**.

- Quando compilamos um programa Java, ele não é transformado diretamente em código de máquina do computador. Ele é convertido em um código intermediário chamado **Bytecode**.
    
- A **JVM** interpreta e executa esse Bytecode em qualquer sistema operacional que tenha a Máquina Virtual instalada. É por isso que dizemos que o Java possui independência de plataforma!
    

#### 3. Características Fundamentais (Anota aí!)

- **Tipagem Forte e Estática:** No Java, cada variável deve ter um tipo de dado bem definido desde o momento de sua criação. Isso evita surpresas e erros em tempo de execução.
    
- **Gerenciamento Automático de Memória (_Garbage Collector_):** Você não precisa desalocar manualmente a memória que seus objetos usam. O Java possui um coletor de lixo automático que limpa a memória inutilizada em segundo plano.
    
- **Orientação a Objetos e Reutilização:** Permite a criação de arquiteturas modulares, facilitando o desenvolvimento seguro por meio da componentização.
    

#### 4. Onde o Java é Utilizado na Prática?

O Java é extremamente versátil e está presente em diversos cenários da tecnologia atual:

1. **Sistemas Corporativos e Backend:** É amplamente adotado em grandes empresas para construir APIs e sistemas de alta complexidade.
    
2. **Microsserviços e Nuvem:** Utilizado na criação de microsserviços resilientes e escaláveis.
    
3. **Persistência e Mapeamento de Dados:** Trabalha perfeitamente em conjunto com _frameworks_ de mapeamento objeto-relacional (ORM), como o **Hibernate / JPA**, para interagir com bancos de dados relacionais.
    

### 📝 Resumo do Professor para Revisão Rápida

- **Linguagem:** Orientada a Objetos, com tipagem forte.
    
- **Execução:** Compilação para _Bytecode_ + Interpretação pela _JVM_.
    
- **Recurso de Memória:** Possui _Garbage Collector_ para gerenciar a memória.
    
- **Uso:** Sistemas Web, APIs, Arquiteturas de Microsserviços e Persistência em Bancos de Dados.
