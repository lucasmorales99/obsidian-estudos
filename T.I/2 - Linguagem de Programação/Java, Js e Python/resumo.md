Acomodem-se, turma! Vamos fechar o nosso **Guia de Tecnologia** com chave de ouro fazendo uma análise comparativa direta entre as três linguagens que estudamos: **Java**, **JavaScript** e **Python**.

|**Característica**|**Java**|**JavaScript**|**Python**|
|---|---|---|---|
|**Paradigma Principal**|Orientada a Objetos|Multiparadigma (Baseada em Eventos/Protótipos)|Multiparadigma (Procedural, OO, Funcional)|
|**Sistema de Tipagem**|Forte e Estática (definida em compilação)|Dinâmica e Fraca|Dinâmica e Forte|
|**Execução**|Compilada para _Bytecode_ (roda na JVM)|Interpretada / Compilada _JIT_|Interpretada (linha por linha)|
|**Sintaxe & Estilo**|Rígida, verbosa, usa chaves `{}` e `;`|Flexível, usa chaves `{}`|Limpa, expressiva, indentação obrigatória|
|**Foco de Atuação**|_Backend_ corporativo e APIs robustas|_Frontend_ (Navegador) e _Backend_ (Node.js)|Ciência de Dados, IA, Automação e _Backend_|
|**Frameworks / Usos**|Spring, Hibernate / JPA|React, Vue.js, Node.js|Django, Flask, SQLAlchemy|

**Pontos-Chave para Lembrete Rápidos:**

- **Tipagem:** O **Java** exige declaração de tipos explícita; o **JavaScript** altera tipos livremente em tempo de execução; o **Python** infere o tipo dinamicamente, mas não permite misturar tipos incompatíveis sem conversão explícita.
    
- **Execução:** O **Java** necessita da **JVM** para rodar seu _Bytecode_ em qualquer sistema; o **JavaScript** é o motor nativo dos navegadores para manipular a interface (DOM) e requisições assíncronas (Ajax); o **Python** foca na leitura limpa do código e produtividade.
    
- **Aplicações:** Todas atuam no _Backend_ (seja via Java, Node.js no JS ou Django no Python), mas cada uma reina em seu ecossistema principal: Java em sistemas corporativos, JavaScript na interatividade web/Front-End e Python em inteligência artificial e análise de dados.
