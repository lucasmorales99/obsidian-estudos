### 🎓 Aula: Introdução à Linguagem Python

#### 1. O que é o Python?

O **Python** é uma linguagem de programação de alto nível, interpretada, de **tipagem dinâmica** e multiparadigma (suporta programação orientada a objetos, estruturada e funcional).

Ela foi projetada com um foco central: **legibilidade do código e simplicidade**. A filosofia do Python busca permitir que o desenvolvedor escreva programas expressivos com menos linhas de código se comparado a linguagens de tipagem forte e estática.

#### 2. Sintaxe Limpa e Indentação Obrigatória

Ao contrário de linguagens como Java ou C, que utilizam chaves `{}` e ponto e vírgula `;` para delimitar blocos de código e instruções, o Python utiliza **espaçamentos e indentação obrigatória**.

- Se a indentação estiver errada, o programa não roda! Isso força o programador a manter um código limpo e organizado por padrão.
    

#### 3. Características Principais (Anota aí no caderno!)

- **Tipagem Dinâmica e Forte:** As variáveis têm seus tipos definidos dinamicamente em tempo de execução, mas a linguagem impede operações entre tipos incompatíveis sem uma conversão explícita.
    
- **Linguagem Interpretada:** O código-fonte é executado linha por linha por um interpretador, facilitando o teste rápido e a prototipagem.
    
- **Multiparadigma:** Permite estruturar o código utilizando desde funções simples até abordagens avançadas de Orientação a Objetos.
    
- **Baterias Inclusas (_Batteries Included_):** Vem acompanhado de uma biblioteca padrão vasta, pronta para manipular arquivos, realizar operações matemáticas e lidar com protocolos de rede.
    

#### 4. Onde o Python domina no Mercado?

Devido à sua versatilidade, o Python se tornou a linguagem padrão para diversos ecossistemas modernos:

1. **Ciência de Dados, IA e Business Intelligence:** É a linguagem número um para análise de dados, aprendizado de máquina (_Machine Learning_) e criação de painéis institucionais.
    
2. **Desenvolvimento Web (Backend):** Utilizado para construir APIs e aplicações web robustas por meio de _frameworks_ como **Django** e **Flask**.
    
3. **Automação e Scripts:** Excelente para a automação de rotinas administrativas e integração de sistemas.
    
4. **Persistência de Dados (ORM):** Integra-se facilmente com bancos de dados relacionais utilizando bibliotecas ORM como o **SQLAlchemy**.
